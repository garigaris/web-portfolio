## Что сделано

- Установлен Hugo на macOS.
- Создан статический сайт.
- Настроен локальный Git-репозиторий.
- Репозиторий связан с GitHub.
- Подключена тема Blowfish через Git submodule.
- Настроен деплой через GitHub Pages и GitHub Actions.

## Происхождение контента

Материалы подготовлены автором для учебного веб-портфолио. Использованы Hugo Framework, тема Blowfish, GitHub Pages и GitHub Actions. При необходимости автор вносит изменения по запросу преподавателя.
